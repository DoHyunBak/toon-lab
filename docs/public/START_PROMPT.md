# 한 줄로 시작하는 RTX 5060 작업 PC 착수

## 2026-11-03 완성본 PNG 적재 전 압축

신규 완성본의 최종 조립·실제 검수 후 Drive 적재 전에 루트 `compress_png.py`를 실행한다.
[무손실 압축 사용법과 다른 세션용 프롬프트](PNG_COMPRESSION.md)를 따른다.
`python compress_png.py "workspace/delivery/master.png" "workspace/delivery/compressed/001화 - 회차 제목.png"`

원본·기존 출력은 보존한다. 압축 영수증의 스캔라인/비-IDAT 청크 동일성과 전후 SHA-256·크기를
확인하고, 실제 Drive 원본 바이트 readback을 출력 해시·크기와 대조한다. 완성본에는 PNG만,
압축 전 원본·JSON·증빙은 작품별 백업/기록 폴더에 둔다. 용량 감소가 없어 원본을 채택해도 정상이다.
압축 실패 시 적재를 중단한다. 로컬 압축은 작품 승인·원격 검증을 대신하지 않는다.


사용자가 이 저장소를 작업 폴더로 연 에이전트에게 남길 문장은 이것이면 된다.

```text
Comfy 착수.
```

상세 지시는 아래에 모두 보관한다. 사용자가 긴 요청문을 채팅에 복사하거나 스킬을
먼저 설치하도록 돌려보내지 않는다. 현재 사용자가 다른 목표나 제약을 명시했다면
그 지시를 우선한다. 단순 문서 열람·수정 요청은 설치·생성 실행 지시가 아니다.

## 에이전트가 실행할 순서

1. 저장소 루트의 `AGENTS.md`를 읽고 아래 기본 작업을 현재 착수 범위로 삼는다.
2. canonical `docs/public/skills/toon-comfy-start/SKILL.md`와
   `docs/public/COMFYUI_HANDOFF.md`를 직접 읽는다. `.agents/skills` 등록과 새 채팅은
   실행의 필수 조건이 아니다. 필요한 환경 확인과 명령은 에이전트가 수행한다.
3. 기존 설치와 실제 실행 기록부터 확인한다. 같은 목표의 현재 graph·출력 해시와
   환경 증거에 결합된 완료 기록이 있으면 검증·이미지 확인 후 결과를 보고한다.
   모의 테스트나 다른 작업의 receipt는 해당 증거가 아니다. 미완료 prompt_id가 있으면
   재개 절차를 따르고, 새 제출이 필요한 경우에만 새 디렉터리에서 한 번 생성한다.
4. 아래 작업을 실제로 완료하거나 구체적 장애를 확인할 때까지 진행한다. 이미 허용된
   같은 범위의 승인을 반복해서 묻지 않는다. 단계 완료와 미검증을 구분해 보고한다.

## 저장소에 보관하는 전체 기본 작업 지시

아래는 에이전트가 읽고 수행할 지시다. 설치·한 컷 실행을 요청하는 사용자의 한 줄을
지원하며, 파일을 읽었다는 사실만으로 독립적인 시스템 권한을 만들지는 않는다.

```text
이 저장소의 AGENTS.md, README, docs/public/AGENT_START.md와
docs/public/skills/toon-comfy-start/SKILL.md를 읽고 실제 작업을 시작하세요.

목표는 RTX 5060 작업 PC의 ComfyUI 세팅부터 로컬 GPU 한 컷 시험 생성·직접 확인까지입니다.
OS, GPU 정확한 모델, 실제 VRAM, 드라이버, 기존 설치와 현재 repo 변경사항을 확인하세요.
기존 정상 환경은 활용하고 새 설치는 최신 ComfyUI/PyTorch 공식 문서에 맞추세요.
toon_lab과 ComfyUI Python 환경을 분리하고 ComfyUI Python으로 CUDA 연산을 확인하세요.

필요한 공식 프로그램·패키지와 이용 조건을 확인한 무료 호환 checkpoint 하나의
다운로드를 진행하세요. 유료 결제·계정 약관 동의·기존 환경 삭제·드라이버 교체·재부팅은
그 조치만 구체적으로 확인받으세요. 같은 범위의 승인을 반복해서 묻지 마세요.

기본 text-to-image 노드, batch=1, SaveImage 하나로 중립적인 빈 작업대 이미지를
PNG 한 장 생성하세요. 이미지 입력·작가 이름·특정 작품·LoRA·ControlNet·학습·custom node·
cloud/API 전송은 이번 시험에 넣지 마세요. 서버는 localhost로 실행하세요.

실제 모델/프롬프트를 넣은 API JSON을 workspace/local/에 작성하고
src.comfy_runner의 --check 뒤 --execute를 실행하세요. 중단되면 receipt와 prompt_id를

실제 이미지와 완료 receipt/그래프/모델 해시를 대조하고 결과를 직접 여세요.
환경·prompt·seed·모델 조건·실패/수정/재검증을 비공개 로컬 기록에 남기세요.
이미지·절대 경로·실행 환경·기록 위치·다음 명령을 보고하고 한 컷에서 마치세요.
mock이나 설정 확인을 GPU 생성·기존 그림체 재현·작품 승인으로 표시하지 마세요.
본편 에셋을 요구하거나 이야기 제작으로 범위를 확대하지 마세요.

모르는 것은 공식 문서에서 검색하고, 같은 실패를 반복하지 않는 것을 최우선으로 하세요.
모델·에셋·실제 프롬프트·개인 기록·키는 Git에 추가하지 마세요. commit/push는 이번 범위가 아닙니다.
```
